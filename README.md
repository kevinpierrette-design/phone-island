# Phone Island

Le site de Phone Island : réparation de smartphones à domicile dans les 34 communes de Martinique.

- `index.html` : l’accueil (comment ça se passe, la zone et le prix du déplacement)
- `reparations.html` : tout ce qu’on répare
- `tarifs.html` : les prix des réparations, de l’entretien et du nettoyage
- `boutique.html` : iPhone neufs et reconditionnés, AirPods et accessoires
- `rachat.html` : le rachat de votre iPhone
- `rendez-vous.html` : prendre rendez-vous sur WhatsApp
